Python 3.10+ is required. Install the exact package versions in `requirements.txt`.

    python -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    jupyter notebook notebooks/1173808_Assignment1.ipynb

Run all notebook cells in order. Locally, place the released training CSV at
`data/train.csv`; on Kaggle, attach the dataset and enable **T4 x2**. The notebook
automatically locates Kaggle's `train.csv`, writes figures/data artefacts, and saves
`models/1173808_Assignment1_final.joblib`.

For a new CSV with the same ten feature columns:

    python predict.py data/new_beans.csv data/predictions.csv

The output CSV contains one `Class` column. `predict.py` locates the submitted model
beside itself. No separate preprocessing script is needed because the final
model is saved as a self-contained scikit-learn Pipeline (StandardScaler +
RandomForestClassifier) that automatically handles feature scaling and ordered feature mapping.
